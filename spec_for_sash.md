Create a reusable vertical graduation sash component for a HUST graduation invitation website.

REFERENCE
Use the provided sash reference image as the authoritative visual source for:
- the HUST crest/logo
- maroon tone
- overall proportions
- pointed lower end
- typography hierarchy

IMPORTANT LOGO RULE
The HUST crest/logo must match the provided reference exactly.
Do NOT redraw, simplify, reinterpret, stylize, stretch, distort, replace, or generate a fake institutional logo.
Preserve the original logo proportions and visual details.
If implementing the website, use the supplied official logo asset directly as an image/SVG layer.

DESIGN
Create ONE SIDE of the graduation sash only, as a long vertical ribbon.

Shape:
- narrow vertical sash
- straight top
- long body
- sharp V-shaped pointed bottom
- thin double-line border in muted warm gold
- subtle fabric texture, almost invisible
- no glossy 3D effect
- no heavy shadow

Primary color:
deep HUST maroon, around #7E1719 / #861B1D

Accent:
muted antique gold, around #C69A54

Text:
warm white / ivory for “HUST”
muted gold for the graduate name and year

LAYOUT — TOP TO BOTTOM

1. Official HUST crest/logo
   - centered
   - leave generous breathing room around it
   - approximately 65–72% of sash width

2. Large vertical “HUST”
   - bold geometric sans-serif
   - white / ivory
   - displayed vertically similar to the physical sash reference
   - visually dominant element

3. Thin horizontal gold divider

4. Graduate name:
   TRẦN
   QUANG
   HUY

   - centered
   - elegant serif
   - uppercase
   - muted gold
   - smaller than HUST
   - generous line spacing

5. Thin horizontal gold divider

6. Year:
   2026
   - centered
   - serif or clean small caps
   - muted gold

7. V-shaped pointed ending

STYLE
The sash must feel:
- academic
- masculine
- minimal
- premium
- elegant
- HUST-specific
- suitable for a mobile graduation invitation website

Avoid:
- oversized crest
- thick gold frame
- gradients
- glowing effects
- glassmorphism
- decorative flourishes
- extra icons
- fake fabric folds
- multiple logos

WEB IMPLEMENTATION
Build it as a reusable component named GraduationSash.

Desktop width: ~84–96px
Mobile width: ~58–72px

It should be usable on the LEFT edge of invitation sections.

Do not make it a navigation sidebar.

The sash can partially overlap a card or photograph by 10–18px to create an editorial layout.

Variants:
- full: crest + HUST + TRẦN QUANG HUY + 2026
- compact: crest + HUST + 2026

The full version should be the primary identity element of the website.
